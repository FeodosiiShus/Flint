# Flint

Flint is a personal fork of [Zed](https://github.com/zed-industries/zed). It is built only for macOS on Apple Silicon (`aarch64-apple-darwin`), only in GitHub Actions, by the [`build-macos.yml`](.github/workflows/build-macos.yml) workflow.

## Getting a build

- Every push to `main` produces a DMG as the `flint-macos-aarch64` artifact of the workflow run (Actions tab → Build macOS → the run → Artifacts).
- Every `v*` tag produces a GitHub Release with the DMG attached.
- Any branch can be built manually: Actions → Build macOS → Run workflow.

To cut a release:

```sh
git tag vX.Y.Z
git push origin vX.Y.Z
```

## First launch

The app is ad-hoc signed and not notarized, so macOS Gatekeeper blocks it after download. After copying it to `/Applications`, remove the quarantine attribute:

```sh
xattr -dr com.apple.quarantine "/Applications/Zed Dev.app"
```

The app is built on the `dev` release channel and is named "Zed Dev". Dev builds never check for updates, so it never auto-updates to official Zed.
