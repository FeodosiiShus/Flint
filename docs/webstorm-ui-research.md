# WebStorm UI research: the reference for Flint's WebStorm-style look

## 1. Scope and sources

This document records how JetBrains WebStorm looks and behaves, as the reference for Flint's WebStorm-style UI. It describes the newest documented release, WebStorm 2026.2: every WebStorm Help page used here carries the header “WebStorm 2026.2 Help” and the footer date 17 August 2026, and the release post is dated 16 July 2026.

The Islands theme is the default look since WebStorm 2025.3 (opt-in Beta from 2025.2.3, prototypes in the 2025.2 EAP). WebStorm 2026.1 and 2026.2 brought no chrome redesign, so the 2025.3 Islands look is the current one.

Allowed sources, and the only ones used: jetbrains.com/help/webstorm (and jetbrains.com/help/idea for pages shared by all IntelliJ-based IDEs), plugins.jetbrains.com/docs/intellij (IntelliJ Platform SDK docs and UI Guidelines), blog.jetbrains.com, `jetbrains.com/<product>/whatsnew` pages, and the official screenshots and images embedded in those pages (including resources.jetbrains.com/help/img, which hosts the Help screenshots).

Rule: anything that is not stated in those sources is written “Not documented in official sources”. JetBrains source code (the intellij-community repository on GitHub, its theme JSON and theme metadata files), GitHub issues, Reddit, Medium and Stack Overflow are not used, even where they would give a number.

Exception: the tool window bar icon artwork (`assets/icons/tool_window_*.svg`), the choice of which IntelliJ icon stands for which Flint panel, and the stripe icon size were taken from the intellij-community repository at commit `0ad391f70a62eabbec6db656f473e1284e1110a9`, at the request of the Flint author. Verified there: `JBUI.CurrentTheme.Toolbar.defaultStripeToolbarButtonIconSize()` is 20 and `defaultStripeToolbarButtonSize()` is 40×40 (`platform/util/ui/src/com/intellij/util/ui/JBUI.java`); the More Tool Windows button uses `AllIcons.Actions.MoreHorizontal` (`platform/platform-impl/src/com/intellij/toolWindow/MoreSquareStripeButton.kt`); the Commit tool window uses `AllIcons.Toolwindows.ToolWindowCommit` and the Version Control tool window `AllIcons.Toolwindows.ToolWindowChanges` (`platform/vcs-impl/resources/META-INF/VcsExtensions.xml`). Apart from this exception and Exception 2, nothing in this document comes from JetBrains source code.

Exception 2: the default colours of Flint's chrome (the `theme_overrides."Eva Dark"` block of `assets/settings/default.json`) were taken from `platform/platform-resources/src/themes/islands/ManyIslandsDark.theme.json` (theme name "Islands Dark", `parentTheme` `ExperimentalDark` = `expUI/expUI_dark.theme.json`) of the same commit, at the request of the Flint author. Resolved values used: main-window-bg `#26282C`, tool-window-bg `#191A1C`, popup-bg `#26282C`, popup-border `#33353B`, control-border `#40434A`, toolbar-bg-hovered `#FFFFFF17`, toolbar-bg-pressed `#FFFFFF29`, selection-bg-active `#2A4371`, accent-brand-bg `#3871E1`, text-default `#D1D3D9`, text-muted `#9FA2A8`, text-secondary `#73767C`, text-disabled `#4C4F56`, icon-default-stroke `#C3C5CB`, icon-disabled `#5F6269`, and the `RecentProject.ColorN.Avatar.Start` colours. Also read there: `ScrollBar.thumbColor` `#80808059` and `hoverThumbColor` `#8080808C`, `ToolWindow.DragAndDrop.areaBackground` `#366ACF4D`, the editor tab colours `EditorTabs.underlinedTabBackground` `#233558` and `underlinedBorderColor` `#2E4D89`, `Island.borderWidth` 6 (the documented default is 5) and `Island.arc` 20, the macOS window header height 40 (`CustomHeader.kt`, `HEADER_HEIGHT_NORMAL`), the main toolbar icon size 20 and button size 30×30 (`JBUI.java`), and the tool window header height 41 (`JBUI.CurrentTheme.ToolWindow.defaultHeaderHeight()`). The editor colour scheme of Islands Dark (`IslandSchemeDark.xml`) is not used: the code stays Eva.

Exception 3: the editor tab strip metrics of Flint (strip height, pill size, radius and insets, label font and colour blend, icon and close slot sizes, absence of dividers, pill colours) were taken from intellij-community at commit `0ad391f70a62eabbec6db656f473e1284e1110a9`, at the request of the Flint author. The Islands Dark tabs are `IslandsTabPainter`/`IslandsTabPainterAdapter` in the platform tabs code, with the colours from `platform/platform-resources/src/themes/islands/ManyIslandsDark.theme.json`. Verified values: the tab strip row is 41 px (`JBUI.CurrentTheme.ToolWindow.defaultHeaderHeight()` in `platform/util/ui/src/com/intellij/util/ui/JBUI.java`, used through `EditorTabbedContainer.kt` and `ToolWindowHeader.kt`) and 31 px in compact mode (`ToolWindow.Header.height.compact` in `darcula.theme.json`; that it reaches the Islands theme through the Darcula base is an inference [INF]); the selected tab is a rounded pill of 28 px height (compact 24) inset 4 px from each label edge (compact 2), with radius 6 (compact 4) from `MainToolbar.Button.arc` and a 1 px border drawn inside, and no underline (`IslandsTabPainter.kt`); there are no dividers between tabs, because `IslandsTabPainterAdapter.paintBackground` never calls `paintBorders` (`IslandsTabPainter.kt`, `EditorTabPainterAdapter.kt`); the first tab sits 3 px from the strip edge (`IslandsTabPainter.kt` `firstTabOffset`), so the visible gap between pills is 7 px (compact 3) [calc]; the label border is 8 px on the left and right (compact 6 and 4) with content insets 0,4,0,2 (`ManyIslandsDark.theme.json` `tabInsets`, `tabContentActionsRightInsets`); the icon-to-text gap is 4 px (`EditorTabbedContainer.kt`); the close and pin button is a 16×16 slot on the right that stays reserved on every tab (`CloseTab.kt`, `ActionPanel.java`, `closeSmall.svg`); the minimum label width is 50 px with no maximum (`SingleRowLayoutStrategy.java`); the modified marker is a 13×13 box holding a 6 px dot (`CloseTab.kt`); the label font is Inter 13 px regular for all states (`EditorTabbedContainer.kt`, `LafManagerImpl.kt`); the unselected label colour is the text colour blended toward the strip background with `sqrt(bg²·0.3 + fg²·0.7)` (`unselectedBlend` 0.7 in `ManyIslandsDark.theme.json`, `ColorUtil.java`, `EditorTabbedContainer.kt`), which gives `#AFB1B6` for `#D1D3D9` over `#191A1C` [calc], with the file icon at alpha 0.75 (`unselectedAlpha`); hovered and selected labels use the full text colour; pill colours: selected in the active group fill `#233558` and border `#2E4D89`, selected in an inactive group fill `#26282C` and border `#40434A`, hover fill `#FFFFFF17` with no border (`ManyIslandsDark.theme.json`, `IslandsTabPainter.kt`). Not verified there [INF]: the file-type icon pixel size (16 px assumed), the colour of the modified dot (`IconBadge.infoBackground`, `#548AF7` by default), the compact-mode close-slot paddings and the left-side close button paddings. Flint's own deviations from these values are listed in the README under "Known differences from IntelliJ".

The statement above that nothing outside the first exception and Exception 2 comes from JetBrains source code therefore also excepts Exception 3: the tab strip values listed there are the only other source-derived ones.

### 2.2 Tool window bars

## 4. Settings added

| Setting | Default | Effect | Restore the old look |
|---|---|---|---|
| `tool_window_headers.show` | `true` | A header row (title, options, hide) at the top of every dock island | `"tool_window_headers": { "show": false }` |
| `tool_window_headers.always_show_actions` | `false` | Header actions are visible only while the tool window is hovered or focused; `true` keeps them visible, like WebStorm's “Always show tool window header icons” | Not a look change; irrelevant when `show` is `false` |
| `islands.dim_inactive_window` | `true` | Title bar widgets and tool window bar buttons are drawn at opacity 0.56 while the window is inactive | `"islands": { "dim_inactive_window": false }` |
